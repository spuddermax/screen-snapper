A window tiling extension for Linux Cinnamon

Snap windows to an eighths grid. Then drag the grid.

Screen Snapper replaces Cinnamon's edge tiling with a grid of 4 columns by 2 rows (2 by 4 on a portrait screen). Hold Ctrl while you drag a window and it lands on the grid. Ctrl-drag the edge two windows share and the grid line moves, taking both windows with it.

Try it now in your browser ↓ Install

Free and open source (MIT) · Cinnamon 6.0 to 6.6 on X11

Ctrl + drag a window

Drop it on the grid

Bands 50 px either side of each grid line and screen edge decide which cells the window fills: half, a quarter, three quarters, a strip, or the whole screen. 30 shapes in all. The middle of a cell never snaps.

Ctrl + drag a shared edge

Resize the grid itself

The line under that edge moves across the whole monitor, and every window on it follows live. Add Shift to snap the line back to even eighths. Without Ctrl, an edge resizes just that window.

Super + Ctrl + G resets

A grid for every workspace

Each monitor and each workspace keeps its own layout, saved across logins. Landscape screens get 4 × 2, portrait screens 2 × 4.

    KeysEdge on a grid lineEdge on the screen edge
    noneResizes only that window, as usual. The window leaves the grid and stops following line moves.Resizes only that window and it leaves the grid.
    CtrlMoves the grid line across the whole monitor. Every grid window with an edge on it follows, live. The line stops 200 px from its neighbours and the screen edges.Nothing moves.

    A line can't get closer than 200 px to the next line. When the edge you're dragging reaches that point, the drag carries on smoothly with the next line instead of stopping: that line takes over right where your edge is, every edge that was on your line moves onto it, and your original line goes back to where it was when the drag started. The edge never jumps, so you can size the window precisely past lines hidden inside a window. It works the same dragging back. If carrying on would squeeze a window to nothing, the edge stops at 200 px instead.

    The keys are checked the whole time you drag, not just when you start. Press Ctrl partway through and the drag switches to moving the line; the window goes back on the grid if it had started to resize on its own. Release Ctrl and the line returns to where it was before the drag, and the drag carries on as a plain resize of that one window.

    Snap rules

    The pointer position, not the window's edges, picks the band. Along each axis the pointer is either on an edge band, on a line band, or in the open middle of a cell. In the open middle on both axes, nothing snaps. Otherwise the first matching rule applies.

    How it behaves on the desktop

    • Snapping and moving lines only happen while Ctrl is held. Without Ctrl, dragging just moves or resizes a window, and clicking does nothing.
    • A grid line spans the whole monitor. Moving it in one row moves it in every row.
    • Only windows placed by the grid follow a line move. Each remembers which cells it covers. Moving or resizing a grid window without Ctrl drops it from the grid; snapping it again with Ctrl puts it back.
    • Each monitor and each workspace keeps its own grid, saved so it survives logging out. Super+Ctrl+G puts the grid on the monitor under the pointer, on the current workspace, back to even eighths.
    • A window's own minimum size can stop a line before the 200 px limit.
    • Ctrl+Shift while moving a window (not an edge) shows Shift's edge-snapping targets instead, and the grid doesn't snap.
    • Escape cancels an edge drag and puts every window back. Closing the window you are dragging cancels it too.
    • On the desktop the grid lines aren't drawn during an edge drag; only the windows move. This page draws them so you can see what is happening.
    • Sizes here are for 100% scale; on a HiDPI screen the 50 px bands and 200 px limit scale with it.

    Install

    You need Cinnamon 6.0 to 6.6 on X11 (Linux Mint 21 and 22 qualify), plus git and python3. Clone the repository and run the install script; it links the extension into Cinnamon and turns it on.

    git clone https://github.com/spuddermax/screen-snapper.git
cd screen-snapper
./install.sh

    Keep the folder where you cloned it, and run ./install.sh again after git pull to update. To turn it off, use System Settings → Extensions; Cinnamon's own edge tiling comes back. Full details are in the README.
